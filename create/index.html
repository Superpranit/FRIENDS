Memory Box Studio

Drop in your splat memories, pick the photo for the print, and get a finished memory box: a poster with a hidden QR that opens into a glowing void of your moments.

Who or what is this box for?

2Add memories

Each memory is a 3D splat .ply made from a photo with Apple SHARP. Add 1 to 12. They play in this order; the first floats highest.

    3The print

    One memory becomes the poster. Scanning it turns the photo into light and opens the box right inside that memory.

    Without it, the print uses a render of the splat, which is softer.

    The QR on the print points here, so decide before building.

    ✓Your files

    ↑Publish to GitHub

    Puts the box online at your address in about a minute. You need a GitHub token that can create public repositories: make one here (tick public_repo), then paste it below. It is only sent to GitHub and is not saved.

    ↑Put it online

    Unzip and upload every file, keeping the folders, so the box's index.html is served at the address you chose (it must be https for the camera).

    Memories, prints and tokens never leave this browser, except the files you publish. A published box is a public web page: anyone with the link or the print can open it.
